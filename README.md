# Капелька — выпуски

Здесь лежат готовые версии приложения «Капелька» (мягкие напоминания пить воду) для Android.

## Как поставить в первый раз

1. Откройте на телефоне страницу [последнего выпуска](https://github.com/Alex4124/kapelka-releases/releases/latest).
2. В разделе «Assets» нажмите на файл `kapelka-….apk` и скачайте его.
3. Откройте скачанный файл. Если телефон спросит, разрешите установку из браузера.
4. На Samsung сначала выключите «Автоблокировку»: «Настройки → Безопасность и конфиденциальность → Автоблокировка». После установки её можно включить снова.

## Обновления

Ставить новые версии вручную не нужно. Приложение раз в день проверяет этот репозиторий и, когда выходит новая версия, присылает уведомление. Нажмите «Обновить» и подтвердите установку. На Samsung на время обновления «Автоблокировка» должна быть выключена.

Все записи, сад и напоминания при обновлении сохраняются. Приложение отправляет в интернет только запрос «нет ли новой версии» — личные данные не передаются.
